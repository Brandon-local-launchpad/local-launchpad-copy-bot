Website Delivery SOP
Local Launchpad — VA Build Instructions


Overview
This SOP covers everything you need to deliver a Local Launchpad website from scratch inside
GoHighLevel (GHL). Follow every phase in order. Do not skip steps or reorder them.


Your role covers:
   •​   Building and configuring the GHL website (all pages)
   •​   Filling in all custom values
   •​   Running copy prompts in Claude to generate all written content
   •​   Running geo research prompts in Perplexity for each location
   •​   Finding H1 keywords in Ahrefs for every page type
   •​   Setting up automations and the chat widget
   •​   Testing everything before marking the job complete


Your role does NOT cover:
   •​   Google Business Profile (GBP) — Brandon handles this separately
   •​   Domain purchase — confirm with Brandon before touching domains
   •​   Client communication — all client contact goes through Brandon


   Note: All copy is generated by Claude (claude.ai). All geo research is generated by
   Perplexity. You need access to both. Login details are sent by Brandon via WhatsApp.
   ⚠️  UK clients only. No toll-free numbers. No +1 dialling. All phone numbers follow UK
   format throughout.

Every page needs an H1 based on real Ahrefs data. The H1 is not a creative decision — it is the
highest-volume relevant keyword for that page's topic and location.
   ⚠️  Always set the country to United Kingdom in Ahrefs before searching. Never use data
   from any other country.



How to Use Ahrefs
   20.​Go to ahrefs.com > Dashboard
   21.​Click Keywords Explorer
   22.​Set country to United Kingdom
   23.​Type your search term and hit Enter
   24.​Find the highest volume result. You want a monthly search volume above 0 to 10. If the
       first term is 0 to 10, modify it as described in the rules below.



H1 Rules by Page Type
Homepage
   •​   Search: [primary category] [primary city]. E.g. landscaper Southampton.
   •​   Pick the highest volume variant. Use this as the homepage H1.


Category pages (Location Category page)
   •​   Search: [category name] [primary city/area]. E.g. lawn care services Southampton.
   •​   If volume is 0 to 10, remove 'services' and retry. E.g. lawn care Southampton (volume 70
        — better).
   •​   Once you have found the best format, apply it to every location. E.g. Lawn Care
        Romsey, Lawn Care Eastleigh. You do not need to re-run Ahrefs for each location — just
        swap the location name.


Service pages
   •​   H1 = [service name] [primary city]. No Ahrefs check needed — use the exact GBP
        service name plus the primary location.


   ⚠️
   •​   E.g. Lawn Mowing and Maintenance Southampton.
        Service pages always use the PRIMARY location in the H1 — not the location they are
   linked from. A service page is always 'Lawn Mowing and Maintenance Southampton', never
   'Lawn Mowing and Maintenance Romsey'.
Location pages
   •​   Search: [primary category] [location name]. E.g. gardener Romsey.
   •​   Pick the highest volume variant. Use this as the H1 for that specific location page.

Phase 4 — GOOGLE MAP EMBED ​
The Google Map Embed custom value places an interactive Google Map on the client's website.
It uses an iframe code taken directly from Google Maps — you do not need access to the
client's Google Business Profile or any Google account to do this.

1. Open a browser and go to google.com/maps

2. In the search bar, type the client's exact business name and press Enter.
  • Use the name exactly as it appears in the Company Name field of the Custom Values sheet.
  • Example: Edens Edge Landscaping

3. The business listing should appear on the left panel. Click on it to open the full listing.

4. Click Share (the icon that looks like an arrow pointing up and right).

5. In the popup that appears, click the Embed a map tab (not "Send a link").

6. You will see a size dropdown — leave this on the default size (Medium).

7. Click the blue COPY HTML button.
  • This copies the full iframe code to your clipboard.
  • It will look something like this:
    <iframe src="https://www.google.com/maps/embed?pb=..." width="600" height="450"
style="border:0;" allowfullscreen="" loading="lazy"
referrerpolicy="no-referrer-when-downgrade"></iframe>

NOTE: You must copy the full iframe code — not just the URL inside it. If you only paste the
URL, the map will not display on the site.



STEP 2 — PASTE INTO THE CUSTOM VALUES SHEET


1. Open the client's Custom Values sheet.
2. Go to the CLIENT CUSTOM VALUES tab.
3. Find the Google Map Embed row (it will be highlighted in amber with "— NEEDS FILLING
IN").
4. Click the cell in the Value column (column C) for that row.
5. Paste the full iframe code.
6. The amber highlight will remain — that is fine. The value is now filled.
STEP 3 — ENTER INTO GHL

1. Log into GHL and open the client's sub-account.
2. Go to Settings (gear icon, bottom left).
3. Click Custom Values in the left menu.
4. Find the Google Map Embed field.
5. Click the three dots next to it > Edit Custom Value.
6. Paste the full iframe code into the value field.
7. Click Save.



STEP 4 — VERIFY IT WORKS


1. In GHL, open the site preview for the client.
2. Navigate to a page that contains the map (usually the homepage or contact section).
3. The map should display as an interactive Google Map showing the business location.

If the map does not display:
• Go back to GHL Custom Values and check the Google Map Embed field.
• Make sure the value starts with <iframe and ends with </iframe>.
• If it only contains a URL (starting with https://), it was not copied correctly — go back to Google
Maps and repeat from Step 1.

COMMON MISTAKES:

✗ Copying the URL from the address bar instead of the iframe code
 Fix: Always use Share > Embed a map > COPY HTML

✗ Clicking "Send a link" instead of "Embed a map"
 Fix: Make sure you are on the Embed a map tab in the Share popup

✗ The wrong business appearing in search results
  Fix: Check the business name matches exactly. If multiple results appear, look for the one with
the correct address and select that listing before clicking Share.

✗ Pasting into GHL but forgetting to click Save
 Fix: Always click Save after pasting — GHL does not auto-save

   ●​ Plants, hedges, and borders should look like typical UK garden species

   ●​   The image should look like it was taken on a real job, not in a studio

Part 3 — Sitemap

A sitemap is a file that lists every URL on the website and tells Google which pages exist and
which ones matter. Without a sitemap, Google has to crawl the site by following links — which is
slower and less reliable, especially for new sites with no backlinks. A sitemap speeds up
indexing.


GHL generates the sitemap for you automatically. Your job is to make sure it only includes the
pages that should be indexed, and that it is generated after all pages are live.
When to Generate the Sitemap

Generate the sitemap after all pages are built and live on the domain. Do not generate it before
the domain is connected — the sitemap will contain the wrong URLs.


 ⚠️ Regenerate the sitemap any time a new page is added or a page URL (slug)
 changes. An outdated sitemap pointing to old or missing URLs can confuse
 Google's crawler.



How to Generate the Sitemap in GHL

   ●​ Click domains & URL redirects

   ●​   Review + Referral Followup Form page — always unselect this
   ●​   Any service or location pages that are not active and live
   ●​   Any placeholder or test pages

   ●​ Click Generate & Save


 Note: GHL generates the sitemap as an XML file at yourdomain.co.uk/sitemap.xml. You
